# 安全说明

## 数据边界

本工具只在用户浏览器中读取本地视频和写入用户明确选择的导出目录。



## 发布安全基线

- 本地服务只绑定 `127.0.0.1`，并校验 Host/Origin/Sec-Fetch-Site、请求大小、客户端数量和心跳 TTL。
- 导出目录使用唯一名称，拒绝覆盖现有文件；中断时清理已写文件或留下 `.incomplete.json` 标记。
- CSV 单元格会防止常见电子表格公式注入；JSON 保留原始值。
- 工程导入限制 JSON 大小、嵌套深度、有效日期、相对路径、字段类型、名称/备注长度、素材数量、重复 ID 和悬空引用。


- 本地历史写入与未引用缓存清理使用同一事务；外部拖拽 ID 必须对应当前素材。
