分镜命名打包器 0.1（版本 0.1.0）
作者：sk0l

第一步：双击“启动器.cmd”。

启动后会先出现选择窗口：
- “新建编排”：打开空白工作区，不会自动载入上次内容，也不会新增空白历史。
- “恢复上一次”：载入最近保存的编排和仍可用的视频缓存。
- “取消启动”：不打开网页，也不启动本地服务。

启动器使用 Windows 自带 PowerShell（无需管理员权限、无需预装 Node）在本机 127.0.0.1:8765 提供静态网页。关闭所有打包器网页标签后，本地服务和启动窗口会自动退出；刷新页面不会误关。

使用流程：
1. 选择视频、选择文件夹，或把多个视频文件夹/多批视频一次拖入总池。总池默认隐藏已放入槽位的素材，需要复查时点击“显示已编排素材”；显示时会标出具体主/补槽位，移回总池后立即出现。
2. 输入当前集号命名前缀（无需填写总集数），把素材分配到主镜头或补镜头槽位；填入最后一个槽位会自动增加下一个空槽。
3. 每个补镜头可填写备注并上下调整顺序。主镜头导出名形如 `3-1.mp4`，补镜头导出名形如 `3-1_补镜头_01_此段有男主近景.mp4`；非法字符会在最终文件名中安全清洗。
4. 总池按浏览器可读取的文件最后修改时间旧→新排列；这是文件时间，不是 Windows 真实创建时间。
5. 历史面板最多保留 20 条。自动保存会更新当前记录，恢复记录时不会重复创建；只有点击“保存版本”才新增独立快照。缓存、权限或原文件位置失效时，重新选择原视频/文件夹即可按文件特征匹配回原槽位。
6. 历史面板的“清空本地缓存/历史”需要二次确认，并会清除本工具在当前浏览器保存的工程和视频缓存。
7. 检查自动生成的文件名，然后下载 ZIP；支持的 Chrome/Edge 也可以逐文件导出到文件夹。未分配素材不会导出。

停止服务：直接关闭所有打包器网页标签即可；也可以回到启动器窗口按 Ctrl+C，或直接关闭启动窗口。

如果启动器提示找不到 `dist\client\index.html`，说明当前目录还没有生产构建产物。请在项目目录运行 `pnpm install --frozen-lockfile` 后执行 `pnpm build`，再双击启动器。启动器本身不要求预装 Node，但重新构建需要 Node.js 与 pnpm。

隐私：所有视频只在本机浏览器中读取和导出，不上传、不登录、不使用 API key。项目 MIT 许可证；第三方许可见 THIRD_PARTY_NOTICES.md。
